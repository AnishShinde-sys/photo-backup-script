# Photo Backup Script Changelog

## [0.2.0] - 2026-07-24

### Added
- Initial release of photo backup script
- Automated detection and backup of photo files
- Intelligent organization by date or flat structure
- Content-based deduplication using SHA256 hashing
- Metadata preservation during file copying
- Configurable source and destination paths
- Support for multiple file formats (JPG, PNG, RAW, HEIC, etc.)
- Dry-run mode for testing
- Verbose and debug logging options
- File size limits and batch processing
- Comprehensive error handling and logging
- Backup summary statistics

### Features
- Cross-platform support (macOS, Linux, Windows)
- Recursive directory scanning
- Incremental backup support
- Configurable via YAML or JSON files
- Command-line interface with multiple options

### Documentation
- Comprehensive README with installation and usage instructions
- Example configuration file
- Troubleshooting guide
- Roadmap for future features
